# SPEAK 持续优化与产品验收

建立日期：2026-10-09。Goal 状态：进行中。当前交付范围：个人与小范围受邀用户可长期使用的雅思口语产品。

## 目标与完成条件

让用户可以独立完成注册或邀请接入、设置、选盘、语音训练、查看可信反馈、回放、重练、自由观点练习、词汇收藏和复习；让运营者能够安装、控制预算、管理内容、备份、恢复和升级。

完整产品需要以下门槛全部满足。代码存在、模拟服务通过、真实接口连通、真人体验验收分别记录；不得把某一层证据当成另一层已经完成。

| 门槛 | 验收方式 | 当前证据与缺口 |
| --- | --- | --- |
| 账号与权限 | 邀请、首次改密、登录失效、管理权限、双账号交叉访问、退出清理 | 已有自动化；持续回归，检查共享设备残留 |
| 训练闭环 | 选盘 → 播报 → 计时录音 → 上传/恢复 → 报告 → 回放/重练 | 已有模拟流程和真实合成语音连通；20 次真人完整练习及失败恢复待验 |
| 自由练习闭环 | 三种表达、修改、历史、隐藏回想、收藏、复习、成长记录 | 已有真实生成及模块自动化；第一轮补成长记录和离开保护 |
| 学习积累 | 复习间隔、日历、积分与分钟券、删除同步 | 自动化可验证；不同活动与时长不能混算 |
| 语音与内容质量 | 真人口音/噪声样本、抽听考官、30 条反馈人工核对、首批题库审核 | 合成人声连通已验证；真人、教学审核仍待完成 |
| PC 与手机 | Edge/Chrome、Android Chrome、iPhone Safari；权限拒绝、切后台、原速计时 | 桌面虚拟麦克风和响应式检查已有证据；真实手机 HTTPS 验收待完成 |
| AI 与费用 | 个人/站点 Key 隔离、预算预留、失败重试不重复计费、用量透明 | 已有自动化及真实调用；费用展示为估算，性能样本仍需积累 |
| 数据与隐私 | 私有音频、密钥加密、账号/记录删除、恢复后删除日志重放 | 核心路径已有隔离测试；完整备份恢复及共享设备检查待补 |
| 安装与运行 | 干净安装、健康检查、worker 恢复、更新、隔离恢复演练 | Windows 本机启动已验证；Docker、HTTPS 部署、完整恢复未验收 |
| 发布与维护 | 测试、构建、安全扫描、清洁源码、README 与远端提交一致 | 已有发布检查；本 goal 每轮继续保存证据 |

完成条件：以上必需门槛有可复现证据，没有未解决的 P0/P1 缺陷，并完成一次实际受邀用户试用与恢复演练。只有届时才将 goal 标记完成。当前版本不能宣称所有真人、真机与部署验收已经通过。

考公、考研和求职等其他内容继续保留在扩展路线中，不作为这一轮雅思产品的完成门槛；避免用无限加功能代替完成现有产品。

## 每轮工作方式

1. 读取本清单和上一轮证据，检查 Git 状态、当前服务及涉及源码。
2. 按风险和用户价值选一组问题，先复现或确认代码路径，再做最小完整修复。
3. 为数据、权限、计费和恢复问题做有意义的回归；涉及界面行为时验证真实页面。
4. 运行适合改动的测试与构建；恢复本机服务，检查健康状态和构建是否对应当前源码。
5. 将去敏后的结论写入本文件或独立轮次记录。详细运行数据保存在被 Git 忽略的 `data/verification/`。
6. 源码发布前运行 `npm run check:release`，确认不包含环境密钥、数据库、真人音频和私人信息；同步 GitHub 后核对远端提交。
7. 清单中的缺口未闭合时保持 goal 进行中。不能以“测试通过”推断真人或真机验收通过。

用户已授权持续优化、现有 API 与月预算、公开源码同步。保留 MIT 与第三方许可。不改变既定 RhineLab 磁盘风格、登录动画速度与选盘返回位置；不恢复插入磁盘或双圆环旋转动画。不得自动购买服务器/域名、提高预算、发布私人材料或把未审核题库标为已审核。

## 第一轮：2026-10-09

本轮检查以当前代码、测试和本机运行状态为依据。检查了本轮已有 Edge 回归生成的观点实验室桌面、手机截图，确认三种表达、历史与素材入口可见；模拟结果有清楚标识。当前没有可用的内置浏览器控制入口，Product Design 的完整流程截图审查仍未完成，没有把旧截图或代码阅读作为当前视觉验收。

| 当前截图步骤 | 页面状态 | 检查结果 |
| --- | --- | --- |
| 1. 电脑端生成观点 | 模拟示例生成成功，历史与三种表达可编辑 | 层级与入口可见；Natural 位于中间，词语与保存入口可见 |
| 2. 手机端打开历史观点 | 390px 竖屏，三种表达纵向排列 | 页面可访问，无横向溢出；底部导航保持单行，长表达需要滚动编辑区域 |

这两张截图仅覆盖观点页面，不能代表全站视觉、键盘、屏幕阅读器或真实手机验收。离开确认与日历链接另由交互回归验证。截图与本轮测试账号数据保存在被 Git 忽略的 `data/verification/`，没有加入公开素材。

确认的缺口与处理：

- 自由练习与 Natural 自评复习没有进入成长日历：接入日历足迹、练习天数、观点练习与表达复习次数。文本练习也能留下足迹。
- 浏览器报告的观点录音时长不能当作服务器检测的语音：日历单独标记，面试音频图表、语音检测和积分仍使用原来可验证的来源。
- 点击站内导航可能丢失未保存观点或练习：增加离开确认；返回编辑、切换观点也检查未保存练习。
- 词汇匹配以子串判断，可能将 `art` 错认成 `party` 中的词语：改为完整词边界匹配，保留大小写、空白与弯引号的归一化。
- 本机没有可调用的 `pg_dump` / `pg_restore`，Docker 也未安装：完整恢复演练仍待完成，不能复用之前的删除重放测试宣称恢复通过。
- 类型检查会扫描被 Git 忽略的旧源码导出目录，导致旧组件被当前接口变更影响、使当前版本无法构建：将 `release` 和 `backups` 排除出项目类型检查。

验证结果：72/72 项单元与集成测试、22/22 项浏览器回归通过；TypeScript 检查与生产构建通过。浏览器测试使用独立数据库、测试账号、模拟服务、虚拟麦克风与加速计时，没有调用真实付费 API。源码及全部本地 Git 引用扫描通过（1140 个文件、1147 个历史对象，无发现项）；安全扫描覆盖已知规则和本机敏感配置，并非对所有未知泄露形式的绝对保证。

本轮页面流程通过：未保存编辑取消离开后仍在原页面、确认后可以导航；未保存回想取消返回或导航后仍保留；保存后日历可打开原观点。数据库验证覆盖 UTC+8 跨日、最近 7/30 天、未来记录不计入近期统计、他人隔离、删除同步和不增加录音统计/积分。

下一轮重点：独立备份恢复、跨页面/浏览器返回时的草稿保护、当前界面证据和部署检查。回归服务日志还观察到一次欢迎页切换期间的响应流提前关闭，未导致对应交互用例失败；需继续确认是否属于导航取消，不将其直接认定为已解决。真实手机、真人声音与教学审核的记录保留在 [验收工作包](验收工作包/README.md)，不能由虚拟麦克风自动代签。
