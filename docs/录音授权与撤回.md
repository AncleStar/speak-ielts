# 录音授权与撤回

在「设置 → 录音说明与数据授权」阅读说明、撤回授权，或前往入门设置重新同意。撤回时会先确认，因为未上传录音将被清除，无法恢复。撤回后仍保持登录，可使用文字练习、词汇、复习、成长日历和已保存报告。

## 撤回后的行为

| 内容 | 处理方式 |
| --- | --- |
| 本浏览器的面试、观点练习与设备试音 | 通知各标签页停止麦克风、播放与上传；释放页面回放音频 |
| 本机未上传录音及分片 | 清除；授权版本检查阻止旧异步写入重新创建 |
| 未保存文字草稿 | 保留原账号、原登录标识和 24 小时期限，不因撤回录音授权删除 |
| 进行中训练或模考 | 结束活动状态，释放未使用的训练时间预留；记录保留，已开始模考标记中断 |
| 已上传录音、转写、反馈及练习历史 | 保留，原保存期限和删除入口继续生效 |
| 尚未完成的转写与反馈 | 暂停后续请求，不自动重试；重新同意后在回答详情手动重试 |
| 已经发出的服务请求 | 无法收回；返回的阶段结果保留，用量正常入账，下一阶段检查授权 |
| 请求发出前取消 | 释放费用预留，用量和费用为 0；用量明细标记「已取消 · 未计费」，不算一次实际调用 |

重新同意会创建新的授权版本。旧上传凭证、旧录音的本机写入与上传仍然失效，不能接着提交已撤回的录音。已保存录音可以手动恢复处理，已完成转写可复用，避免重复识别。录音已到期或根本没有上传时，需要重新作答。

## 多页面与设备边界

同一浏览器通过 BroadcastChannel、存储事件与授权版本同步停止动作；即使登录校验请求正在等待，也先停止录音。通知中不包含账号、音频、文本或 Key。不同浏览器、不同设备或被系统挂起的页面，无法保证即时收到本机通知；返回前台、恢复连接或定期校验后才能停止。服务端独立检查授权，撤回成功后拒绝新的上传与处理申请。

浏览器禁用本机存储时会使用内存并显示限制；若撤回已在服务端生效、但本机清理失败，会提示关闭旧页面并手动清除本站数据。撤回不是删除账号或历史；需要删除的内容请使用报告、观点或账号的删除入口。系统强制关闭、离线及设备权限的真实表现仍需手机验收。

## 升级与验证

`0006_recording_consent.sql` 为用户表增加授权版本，现有同意状态默认沿用版本 0。Windows 本机启动入口自动执行迁移；其他部署先完整备份，运行 `npm run db:migrate`，再重启网页与 worker。升级前已领取的短期上传凭证格式会失效，可在仍有效的授权下重新获取；撤回过且未上传的回答需要重新录音。

```powershell
npx vitest run tests/integration/recording-consent.test.ts tests/unit/local-drafts.test.ts
npx playwright test tests/e2e/recording-consent.spec.ts
```

集成测试使用独立 PostgreSQL 与确定性服务替身，检查旧凭证、暂停、用量预留、阶段结果复用和权限版本。浏览器测试使用 Edge 的实际 MediaRecorder、虚拟麦克风、独立账号、模拟服务与缩短计时；这不代表真人语音、手机或教学效果验收。
