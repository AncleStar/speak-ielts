# Android 与 iPhone 双端实测

已确认两种设备都可用于测试，当前状态仍为「待测」。本文件准备实际操作与记录方式，桌面浏览器尺寸模拟、虚拟麦克风和 Docker 自动化不填作真机通过。

## 开始前

使用手机能访问且证书可信的同一 HTTPS 站点，在 Android Chrome 和 iPhone Safari 中分别测试。手机自己的 `localhost` 指向手机，不是电脑；电脑的局域网 HTTP 地址和忽略证书错误都不能替代这项验收。部署说明见 [部署说明](部署说明.md) 和 [Docker 部署与恢复](Docker部署与恢复.md)。当前本机服务仍只供电脑访问，本工作包没有开放公网服务。

部署者先确认网页与 worker 就绪、正常计时 `TIME_SCALE=1`、考官音频实际可播放，创建仅用于试用的账号。开始前在用量页确认本次使用模拟服务、个人 Key 或站点服务以及月预算；真实调用按现有预算记账，不为了测试提高预算。API Key 只在可信部署的设置界面填写。

每台设备记录型号、系统和浏览器版本、日期、Wi-Fi/移动网络、测试服务模式与步骤结果，保存在私有 `data/acceptance/`。可复制 [设备验收表](验收工作包/设备验收.csv)；录像、截图遮住邮箱、密钥、邀请码与私人声音资料。记录实际结果，尚未执行的项保持「未测试」。

## 两台设备分别完成

| 步骤 | 操作 | 核对与记录 |
| --- | --- | --- |
| 登录与显示 | 登录、完成欢迎、选择话题和磁盘；竖屏/横屏各一次 | 载入按钮可操作，地址栏变化不遮住按钮，文字区域可滚动；退出回到当前磁盘 |
| 权限拒绝 | 第一次请求麦克风时拒绝，然后重试 | 明确提示权限问题，不假装正在录音；允许后可重新检查 |
| 录音与试听 | 在设备检查录制至少 5 秒并完整回放，再试听考官 | 人声确实录到、头尾不漏，音量和播放正常；记录是否需手动点击播放及扬声器/耳机 |
| 单题到报告 | 按原速完成一题，等待处理，回听自己的回答 | 计时和实际录音核对；转写/反馈服务标识正确，播放和拖动进度可用 |
| 后台与锁屏 | 单独开始测试题，录音时切换应用约 10 秒，再回来；另一次锁屏后返回 | 应报告录音中断，保留已录片段；不能把后台静音当有效回答。模考中断不等同训练暂停 |
| 音频打断 | 使用测试题，安排一次来电或另一应用占用音频后返回 | 明确录下是否中断、提示和片段结果；无法安排来电则保留未测，不能用锁屏结果代填 |
| 断网与刷新 | 测试录音后断网提交，再恢复网络；另外一次录音后刷新 | 上传失败可重试且不重复计费；本机片段或恢复限制提示符合实际，不清除浏览器数据 |
| 完整模考 | 保持前台、正常计时完成一套 | 按 750 秒模板核对各阶段和完整报告；阶段限定计时不是完整官方考试总时长的承诺 |
| 学习闭环 | 复盘、同题重练、保存词语、今日复习、成长日历、签到及积分明细 | 记录能再次找到、复习与日历一致，失败/中断不被算成成功练习 |
| 自由练习 | 输入观点、编辑三种表达、隐藏 Natural 练习并保存词语/复习 | 能重新打开个人观点；模拟模式的固定示例不得评价为翻译质量通过 |

首次先各完成「权限、5 秒录音/试听、单题到报告、切后台」；发现失败先记录再修复，其他项保持待测。录音中断测试使用单独会话，不把被故意打断的测试计入 20 次真人完整练习成功率。不能读取恢复片段时保留页面并记录限制，不删除本机数据来掩盖失败。

## 权限恢复与通过条件

拒绝后先在该浏览器的站点权限中重新允许麦克风，并核对系统对该浏览器的麦克风授权，再回到设备检查重试。不同系统版本入口可能不同，以手机实际界面为准；Safari 的播放需要真实点击，网页不能承诺绕过系统的音频策略。权限处理依据 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia#privacy_and_security)。

两台设备分别保存完整结果。正常前台计时/停止误差按项目门槛 ≤1 秒核对；完整练习成功率、处理 P95 和反馈质量需要独立真人样本，单次成功不能推断总体达标。权限、后台或断网出现问题时记录「失败/部分完成」和复现步骤，修复后复验原步骤。真实音频评测和至少 30 条反馈人工审核见 [验收工作包](验收工作包/README.md)。
