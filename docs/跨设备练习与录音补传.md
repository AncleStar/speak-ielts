# 跨设备练习与录音补传

## 使用方式

普通训练在另一页面或设备打开时，显示「接管这次练习」。点击后先说明本机录音与服务端记录的区别，再由用户确认继续。取消确认、查看页面或退出查看页面，都不会暂停原设备的练习。

接管后，联网的原页面在下一次状态检查停止麦克风与播放，保留已录片段；检查间隔为 5 秒，浏览器后台调度、网络和响应时间可能延迟停止。离线页面需恢复网络后才能发现接管。旧设备的未上传录音仍在旧设备，不会自动出现在新设备；请回到旧设备补传。服务端独立核对录制批次，因此网络检测延迟不会让旧片段替代新设备的完整作答。

已开始的模考不支持换设备接续计时。另一设备只读查看，不会因打开页面自动中断模考；需要点击「结束当前模考」并确认才结束。本次计时不能恢复，原设备中断片段仍可补传与复盘。已有本机录音且通过浏览器锁确认录制已停止的崩溃恢复，继续沿用中断处理。

## 录音与额度

- 每次开始生成新的录制批次标识，录音元数据保留实际开始时的标识。新页面不能给旧片段补填自己的新标识。
- 接管前已在服务端取得上传凭证的回答保持原分类，可继续上传。
- 原页面暂停前登记的待上传片段，在 24 小时补传期内保持其分类；后一次暂停不能把另一批次片段升级为完整回答。
- 接管后才登记的旧批次片段保存为中断片段，报告说明来源，不满足当前题目的完整作答要求。已开始训练中缺少批次信息的旧片段同样保留为中断片段；此前已登记的历史回答不重写。
- 无法确认旧页面是否停止时可读取中断副本，不改变原录音；缺号分片可下载原始备份。已完成的记录在结束后 24 小时内接受已知旧批次的中断片段或明确标记的副本，保持完成状态与最近的完整回答。副本处理不暂时隐藏完整回答已取得的目标结果。具体步骤与限制见 [本机录音中断恢复](本机录音中断恢复.md)。
- 已结束的模考在补传期内接受已知录制批次的中断片段，不重开计时、不重新预留整场考试。上传期限、录音授权、题目归属、实际音频时长和额度检查继续生效。
- 中断录音仍占用实际录音时间，不能据此免扣或推测退款。正在进行的训练还包含整题预留，与实际已录时间分别核对。

批次标识用于避免正常客户端的旧操作覆盖新进度，不是设备身份认证。用户登录、归属和当前录音授权仍是访问边界。

## 升级与验证

迁移 `0010_recording_source.sql` 为回答增加录制批次和来源字段。历史回答默认 `accepted`，不会被重新标记。新客户端的开始、暂停、心跳、跳过、推进和结束操作携带所属批次；旧页面会收到状态冲突提示，应先停止并保留片段，再刷新。不要在活跃录音中替换运行时，也不要回滚到缺少接管保护的客户端/服务端组合。

本轮先在独立 PostgreSQL 中复现无确认接管及旧设备完整回答误计，再增加真实 PostgreSQL 的接管、陈旧操作、补传、计费、保留凭证、模考只读和期限检查。浏览器验收使用独立 Edge 上下文、实际 MediaRecorder 与服务端 FFmpeg，分别验证联网及离线恢复接管；ASR 和反馈使用模拟服务，未新增付费调用。最终数量与结果记录在本机验收凭据中。

Windows Edge 的独立浏览器上下文模拟设备存储隔离，不等同于真实 Android/iOS、手机后台录音、公网 HTTPS 或不同系统验收。缺少浏览器锁证明的旧录音仍不能凭经过时间推断已停止；历史不明费用与时长保留，等待独立证据核对。
