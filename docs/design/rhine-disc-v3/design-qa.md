# RhineLabUI v3 · 磁盘交互与入口优化

日期：2026-10-01（Asia/Taipei）。状态：修改、最终构建和整套回归完成，正式服务已重启并通过健康检查。v2 验收存档见 `docs/design/rhine-disc-v2/design-qa.md`。本文内路径相对于项目根目录。

## 本轮修改

1. **进入训练磁盘时闪现旧页面**：样式从依赖挂载后写入的 html 属性，改为首屏服务端已有的页面根属性；3D 加载期间移除旧版磁盘海报，仅显示简短载入状态。同一 Canvas 继续跨选盘、面试页面使用。
2. **返回当前磁盘**：题型、主题、搜索词和选中题号写入当前 URL，同时保存在根布局。页面内返回、浏览器后退、刷新均恢复到当前盘与筛选条件。
3. **记录盘与主页细节**：Blender 重新渲染当前 Rhine 风格盘体，保留双环、透明盖、金属边缘、螺钉及 SPEAK 标签。网页图为 900×900 WebP、38,960 字节。管理员与用户共用的个人主页、记录卡及降级图已替换。主页图文分栏；手机记录图限定在自身列内。
4. **清晰入口**：磁盘页左上与手机页签下方直接展示「积分兑换 / 学习记录 / 成长日历」。主导航与手机底栏同步提供入口，菜单保留其余页面。使用细线、单色图标和小型英文标注适配当前风格。
5. **共用插盘动画**：开始面试完成麦克风连接后，盘体对位、底座显现、插入并锁定，共约 1.35 秒；相机平滑拉开以容纳底座。动画完成后才提交开始事件、播放提问并进入原有计时逻辑。回放从头开始时复用同一动画，音频仍直接响应点击，暂停继续不会反复插盘。
6. **状态与退出**：底座录音灯跟随真实录音状态；开始失败释放屏幕常亮锁，离开页面取消待完成的载入回调。简洁显示、WebGL 失败、减少动态和暂停背景不要求等待这段装饰动画。
