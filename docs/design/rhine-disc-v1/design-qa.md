## 五项核对

- 字体与排版：Arial / 微软雅黑 / 系统中文回退；标题、英语题目、计时为主要层级，编号和辅助说明次之；以真实内容长度适应换行。
- 间距与布局：左右盘体/内容分区，录音主操作优先；回放页保留左侧元信息与历史、右侧播放器与内容页签；手机改为纵向，可滚动浏览。
- 颜色：暖灰纸面、深炭文字、橄榄按钮、琥珀选中；录音红灯只跟随实际录制。保留语义警告色和深色模式。
- 资产：使用本地 Blender 工程导出的真实 GLB 和内置 Image Gen 虚拟头像，无整页图贴图或用 CSS 画假磁盘。即时渲染模型采用较简洁结构、环境光和投影，细节不等同于生成式页面稿中的电影级材质与景深；优先连续操作和加载性能。
- 文案与信息：题数、题号、记录编号、时限、日期、录音时长来自真实服务；保留未审核、模拟转写、处理错误、预算等待和发音未评估提示。

## 有意采用的实现差异

- 录制页不提供可绕过考试计时的播放暂停/拖动；字幕遵守用户设置与模考规则。
- 回放页使用实际音频进度条，没有生成假的音频波形或逐字高亮。
- 未引入几十个后台装饰盘和景深后处理；同时渲染最多 9 个可选盘，保持 Canvas 和对象身份连续。
- Emma 标注虚拟考官，静态头像不冒充实时视频；该设计变更不改变已配置的声音与语音服务。
- 搜索与主题筛选集中在选盘页；保留首页签到积分、关卡和管理员入口。
