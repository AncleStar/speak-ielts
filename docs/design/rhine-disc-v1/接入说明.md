# 磁盘界面接入 · 2026-09-29

原有 Next.js 应用内的真实页面；保留账号、题库权限、麦克风、计时、上传队列、预算、积分和成长记录。

## 页面入口

- `/practice`：训练盘阵列、题型/主题筛选、关键词检索、文字列表、方向键与前后切换；每盘映射现有题目 ID，可打开本人最新记录。
- `/interview/[sessionId]`：真实 TTS 提问、准备、MediaRecorder 录音、上传与完成状态驱动磁盘及底座灯。
- `/answers/[id]`：个人记录盘、真实回放进度/倍速/音量、转写修正、反馈、同题比较、再练；只读本人的数据，管理员仍须原有排查授权。
- `/history`：记录盘列表。首页、签到、成长、设置沿用暖灰/橄榄主题。

本机入口：http://localhost:3000/practice，使用原有账号登录。应用停止后可双击项目目录的 `启动应用.cmd`，通过 `查看应用状态.cmd` 检查服务。

## 动画与性能

3D 为本机 Blender 导出的真实 GLB。Three.js 0.183.2 按需加载；阵列最多复用 9 个盘体，切换保留 Canvas 与盘体身份，不重新载入整个场景。指数缓动与帧间时间相关，支持连续快速点击，不按动画推算考试时间。

提问/回放时双环旋转；只有麦克风录制器实际 recording 时显示红灯。页面隐藏或模型离屏时停止渲染；静止状态结束缓动后停止申请帧。系统及应用的减少动态效果设置关闭持续运动，暂停背景控制也会停用盘体动态；可随时选择“简洁显示”，模型加载失败提供真实 Blender 渲染作为回退。

像素比上限桌面 1.5、窄画布 1.25；持续帧间隔偏高时降至 1。卸载释放几何、材质、纹理、环境贴图、WebGL 上下文和事件。参考 [GLTFLoader](https://threejs.org/docs/#GLTFLoader) 与 [Three.js 资源释放说明](https://threejs.org/manual/en/cleanup.html)。

## 真实数据边界

不把设计稿示例次数/日期/转写存入用户记录；未使用逐字高亮或伪造回放波形。回放进度来自 HTMLAudioElement，录音柱形波形来自麦克风音频分析节点。头像是生成的虚构人物、静态头像，不声称是实时视频或真人考官。

录音期限在 API 中即时检查，不必等待定时清理：超过 30 天后停用播放，文字报告保留。演示数据、未审核题、预算等待、处理失败和发音未评估提示保留。

历史列表的录音数量与时长改为关联聚合，修复已有录音却显示为 0 的问题；集成测试覆盖实际上传后的统计值。
