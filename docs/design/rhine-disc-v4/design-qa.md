# RhineLabUI v4 · 原盘体展示与退出面试

日期：2026-10-01（Asia/Taipei）。状态：实现、浏览器复测与本机健康检查通过。本文路径以项目根目录为基准。

## 当前行为

- 面试和回放恢复原有盘体样式，移除插盘底座、盘体下移、相机为底座让位的动作及新增双环旋转。开始面试不再等待装饰性载入，回放直接响应播放按钮。选盘页原有的阵列、选中与抽取过渡保留。
- 面试准备、连接麦克风、考官提问、准备作答、录音及结束阶段均提供「退出面试」。工具栏随滚动吸附，手机端滚动作答时也能直接退出。
- 退出立即停止考官声音、清除倒计时与答题操作、冻结面试场景；当前录音完成最后一块数据的本地保存后释放麦克风和屏幕常亮锁，再返回当前磁盘。
- 普通训练保留未完成会话与已录片段，可在「学习记录」或首页继续。中断的片段不会被当成该题已完成，继续同一会话时可重新作答。重新点击题库里的载入按钮仍按原规则创建新的自由练习。
- 已开始的模考退出后标为中断，不计为完整完成。先上传已录片段，再关闭会话；上传失败时场景保持暂停，可恢复网络后重试退出。
- 处理启动麦克风期间退出、结束录音与退出同时发生，以及异步请求返回后误恢复面试的问题。迟到的麦克风授权会立即释放设备。

## 验证

生产构建通过，52/52 单元与集成测试通过。整套浏览器回归运行 14 个用例，首轮 13 个通过，发现手机端滚动时退出按钮离开视口；已将工具栏改为吸附定位。中途复测发现工具栏新增内边距挤压了桌面作答按钮，已恢复原有高度。最后构建后定向复测录音回放、普通训练退出、模考退出 3/3 通过（1.3 分钟）；选盘导航此前复测通过。14 个浏览器用例均已分批验证通过，未声称最后重新运行过整套。新用例最初误将自由练习的载入当成继续旧会话，已修正为从真实「学习记录」入口继续。
