## 行为

欢迎标题、品牌字样、从左到右的黑色强调条、数据库说明和中文提示依次出现。真实登录成功后才播放。转场层跨路由保留，题目与模型在其下加载，慢加载时保持欢迎状态并保留跳过入口及等待上限。

就绪后欢迎层淡出，接入 `SELECTING FILES…`、原仓库阵列波形及入场位移；镜头平滑回到产品的自适应构图，题号、横线、题目与导航依次显现。同一个 canvas 持续存在。动画结束恢复操作并把焦点移到磁盘库；按钮与 Escape 可跳过。

仅本次登录后播放，普通返回题库不重播，保留当前选择。未恢复插盘、底座或新增双环旋转。系统减少动态效果、应用暂停背景时直接进入；页面进入后台时暂停计时与 CSS 动画。

## 五项视觉核对

- 字体：保留当前 MiSans、SPEAK 品牌与欢迎层级；参考站的品牌图形不替换应用身份。黑条按实际文本自适应宽度，手机无截断。
- 布局：居中欢迎区、页角品牌与跳过入口分开；桌面沿用右侧信息与下方选盘，手机沿用上方场景、下方题目。
- 颜色：沿用纸色、墨黑和暗色主题变量，强调条反白，状态文字区分准备中与选择中。
- 素材：复用带原始许可的磁盘、字体与现有图形，不新增占位图。原尺寸截图中，欢迎文字、黑条、选题区和磁盘边缘均足够大，可直接检查这些局部，无需额外裁切。
- 文案：保留训练磁盘及个人数据库语义；真实登录、切盘、录音、回放、退出继续走原业务。没有把开发参数或调试控件放入用户流程。
