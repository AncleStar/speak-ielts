# 本机录音中断恢复

面试录音每秒将已产生的分片写入浏览器 IndexedDB，本机最长保留 24 小时。浏览器异常关闭后，首页「个人终端」和原面试页面会列出尚未上传的片段。

1. 点击「恢复中断片段」，将已写入的内容标记为中断录音；不会调用 AI，也不会开启麦克风。
2. 在页面播放器中回放，确认内容后点击「重试上传」。离线时可恢复和回放，上传须联网；失败保留本机片段。
3. 不需要的内容可以点击「丢弃片段」，确认后删除本机音频。已上传的记录须在学习记录中另行删除。
4. 回到原练习重新完整回答。中断片段不能完成关卡、解锁下一关或算作目标达成；模考仍保持中断，不会续接为完整模考。

每段新录音在支持 Web Locks 的浏览器中持有独占锁，直到最后分片与最终状态保存完毕。浏览器关闭或录音页面进程崩溃会释放锁。其他页面不能把仍被占用的原片段恢复为已结束状态或丢弃；不使用「已经过了几分钟」推断录音已经结束，也不把挂起页面的心跳超时当成崩溃。恢复和丢弃操作会再次取得锁，两页同时操作不能接管正在录制的内容。

### 无法确认占用时保留副本

旧版没有占用锁标记，或旧页面仍在录制时，可点击「保留中断副本」。它只复制点击时已经写入的分片，原录音的状态、分片、录制批次与占用锁保持不变；持续录制的页面仍可写入新分片。副本标记为中断，不能代表完整作答、完成必答题或领取完成奖励。

同一原录音、同一登录授权、同一批音频字节重复保存复用副本；原录音增长后可生成不同副本，早先副本不会跟着变长。原片段和副本都沿用原录音的 24 小时本机期限，复制不续期。单个副本最大 25 MB；分片缺号时拒绝生成可补传副本，但可下载原始备份保留所有已存分片。

副本可以离线回放、点击「下载录音」，联网后点击「重试上传」。下载的音频字节与当时存储的分片一致。服务端仍核对账号、授权、题目位置、解码时长、录音额度与模型预算；保存为「本机中断副本」，不重新开启练习或模考。已结束或已完成的原记录在结束后 24 小时内可接收这种补传，已删除的记录拒绝新上传；服务端期限与本机保留期分别检查，过期副本只能在仍未超过本机期限时下载。

普通训练的旧录音阻止开始时，可在原面试页点击「结束当前练习」并确认。服务端确认后释放整题预留，原始分片保持原样；随后「重新练习此题」新建一份练习，新录音不会覆盖旧分片。取消确认不修改服务端状态。离线或同步失败时不会宣称已释放额度，须保持页面并联网确认；旧设备联网发现结束后停止录制。

### 下载与隐私

「下载原始备份」导出 `.speak-recording.json`，包含题目信息、估计时长和逐个序号的音频分片，保留缺号的现场。它不包含账号标识、登录批次、授权版本或 API Key；文件本身包含个人声音，仍应保存在自己的设备上。目前不提供自动导入该格式的入口，不把原始备份当作可跨账号恢复的凭证。下载后文件不会随退出登录、撤回授权或暂存到期自动删除。

账号、元数据与分片在同一 IndexedDB 事务中读取，回放、复制和下载前再次校验当前登录与录音授权；切换账号或序列化期间撤回授权时拒绝继续暴露文件。存储受限时副本会明确标记仅在内存，请保持页面并下载备份，不能承诺关闭后可找回。

多个副本可能包含重叠的声音。报告显示「保存录音累计」，额度按每个实际处理文件的检测时长计，不把重复片段当作独立练习时间或学习进步。晚到的中断片段保留在其他作答中，主回放优先显示最近的完整回答；该片段的处理不会暂时隐藏完整回答已取得的目标结果。

普通练习因未活动而关闭后，手动补传可以通过原有开始准入和暂停流程准备补传名单，再上传保留的片段；准备过程不打开麦克风。日额度、分钟券、月预算、站点暂停、容量、录音同意和状态版本仍会检查。补传准备尚未得到服务端确认时保留本机暂停任务，并明确提示预留额度尚未释放。准备成功后整盘预留释放，片段按实际音频时长核对，重新完整练习需要再次准入。

账号切换、退出登录或撤回录音同意会清除本机私人片段和播放器引用；重新同意不能复活旧片段。恢复界面只使用当前登录与当前录音授权下的数据，跨页面读取以持久存储当前状态为准，避免旧内存副本重新显示已经删除的内容。

保留边界：

- 只能恢复已写入的分片，关闭前尚未产生或写完的最后分片无法找回。损坏或不足以解码的内容可能只能丢弃。
- 浏览器拒绝持久存储时，当前页面的录音可继续使用内存，离开或崩溃后不能保证找回。页面会显示存储受限提示。
- 升级前没有占用锁标记的旧「录制中」片段，以及不能确认锁的浏览器，支持读取副本和原始下载，仍不能接管或自动丢弃原片段。已结束的待上传片段仍可重试。
- 该机制处理同一浏览器内的恢复，不会将本机未上传分片同步到另一设备。已经关闭的模考保持关闭，已有凭证、退出补传名单、已知批次的中断片段或明确标记的本机副本按各自期限接受补传。
- 副本标记表示客户端声明这是中断内容，并不是设备认证或录制时间的密码学证明。服务端会强制按中断处理，不依赖该标记授予完整作答资格。
- 「保留 24 小时」描述本机数据期限，不保证所有过期、撤回授权或已经删除的服务端会话都接受补传。

自动化验收使用隔离数据库、真实浏览器录音器、虚拟麦克风及模拟转写/反馈，不等于真人口语、实际手机系统终止或云部署验收。
