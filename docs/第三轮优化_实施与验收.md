# 第三轮优化实施与验收

日期：2026-09-28。落实上一轮建议中的 1–3，并推进 4–6 的系统验证与验收准备。没有公开部署，没有修改密钥、音色或 100 元月预算。

## 本轮完成

| 项目 | 实际行为 |
| --- | --- |
| 本机启动 | 双击启动后在后台运行；关闭提示窗口不停止服务；代码变化后自动构建；重复点击复用当前进程。新增查看状态、重启、停止入口。 |
| 故障恢复 | 网页或 worker 进程退出后自动恢复，每服务 10 分钟最多 3 次；持续退出时停止并保留日志。只管理本次启动的子进程，已有数据库只复用。 |
| 健康检查 | 数据库与 worker 心跳都正常才返回成功。空闲 worker 不会因没有业务日志被误判离线；心跳 60 秒未更新判异常；不同运行实例不混算。 |
| 预算暂停 | 调用前逐次预留预算；预算不足显示「等待预算恢复」，任务结束本次执行，不进入自动重试。已上传录音按原期限保存，已完成转写保留。恢复后点「检查预算并继续」。 |
| 复用转写 | 重试跳过已完成识别；已有转写和音频指标时，即使录音过期，也可继续文本反馈。尚未识别且录音过期时要求重新作答。 |
| 模考选卷 | 首页优先推荐本人未开始练过的可用试卷，全部练过后推荐最久未练的一套；不再受闯关数量影响。可手选 5 套，查看开始次数、完成次数和最近开始时间，继续未完成会话。 |
| 历史口径 | 未开始、已删除、其他人的记录和加速测试记录不计入正式模考尝试；已开始但中断或放弃计尝试，不计完整完成。 |
| 真实服务验证工具 | 新增 `npm run check:practice -- --real`，用两段本机合成人声及一段静音经过实际上传、转码、识别、反馈与证据校验服务；验证账号和音频事后清理，用量账本保留。 |
| 验收材料 | `验收工作包/` 提供真人录音清单、真实练习与设备记录表、30 题人工审核表；所有真人、真机和人工结论保留待验。 |

## 验证结果

- TypeScript 检查通过；正式构建通过。
- 单元与独立数据库集成测试：7 个文件、48 项全部通过。新增 4 项覆盖模考历史隔离、预算暂停及缓存恢复、过期录音、心跳状态。
- Edge 浏览器测试：9 项全部通过，包括注册、登录、录音报告、加速模考、断网恢复、积分日历与选卷页；320/390/1280 像素选卷页无横向溢出。最终构建又单独复测选卷与继续入口。
- 真实运行演练：重复启动复用进程；核对父进程与命令行后结束本应用 worker，自动生成新 worker 并恢复就绪；手动重启成功。重启前后账号、会话、回答数量与预算一致。记录在 `data/round3/lifecycle.json`。
- 无新增数据库迁移；启动管理与心跳使用现有配置表、独立运行目录。

## 真实服务检查的范围与发现

实际使用本机配置：`qwen3-asr-flash-2026-02-10` + `qwen-plus`，考官与样本人声仍由本机 Kokoro 生成。两轮各 2 段合成人声、1 段静音均通过系统处理与证据可追溯检查。第二轮两段转写与样本文本的归一化 WER 都为 0；这仅代表这些合成样本，不是对真人口音准确率的估计。静音未进入识别及反馈。

两轮按后台配置单价估算费用分别为 0.008642 元和 0.009935 元，合计 **0.018577 元**；以云账单为准。没有增加现有月预算。报告位于 `data/round3/real-practice-before-prompt-fix.json` 与 `real-practice.json`，均明确 `qualityValidated=false`。

第一轮曾把正确的英式 `flat` 建议换成 `apartment`，理由不成立。已将反馈提示更新为 `fb-v1.3`，要求接受正常英语变体、不为凑条目制造错误、将可选建议标明为拓展。复测未再出现这条偏好建议。依据：British Council 明确表示 IELTS 不偏好英式或美式英语，并列举了 flat/apartment 的对应关系。[官方说明](https://takeielts.britishcouncil.org/blog/british-or-american-english-ielts)

**仍存在的质量问题**：第二轮中，模型虽然被要求不重复，仍将名词复数错误同时写入 grammar 与 lexical；提示约束不是可靠的去重保证。结构和引用校验通过也不能证明建议准确。后续应先用真人反馈标注集评估，再实现可验证的重复建议处理，不能把本次合成检查称作教学验收通过。

**速度仍待优化**：第二轮两段处理耗时约 26.7 秒与 49.7 秒。样本不足以计算有代表性的 P95，也不足以宣称达到单题反馈 P95 ≤30 秒的目标。后续需要分阶段耗时记录、足量真实网络样本与输出长度评估。

4. 建议重复、反馈时延的质量改进；题库搜索/收藏、每日计划留待下一轮。

本机启动工具不是系统级守护服务：电脑重启后需要再次启动；能恢复子进程退出，但进程挂起、数据库中断或管理进程自身被结束时仍可能需要手动重启。日志在 `data/run/`，不应把 `.env` 或供应商密钥粘贴到反馈记录里。
