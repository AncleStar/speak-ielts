# 练习暂停、继续与待上传录音

普通训练、题库自由练习和重练可以通过面试室的「退出面试」暂停。暂停后保留原磁盘、题目版本、已完成回答与进度；在「学习记录」点击「继续原题」回到同一次练习。再次开始前会重新检查录音授权、站点暂停状态、AI 预算、活动会话数量和当日可用时长。

## 退出时发生什么

1. 先停止麦克风、考官播放与计时，保存当前录音片段；退出过程暂停场景动画。
2. 服务端确认暂停，释放尚未使用的整盘时间预留。已经提交的录音时长继续计入使用，退出不会退还已用分钟。
3. 退出前留存的录音可以继续补传。暂停名单只包含提交标识、题目位置与授权版本，不包含音频、API Key 或观点正文。新的录音必须先继续练习。
4. 回到当前磁盘；已完成回答不重复作答，中途中止的回答仍需重新完整回答。录音补传、转写和反馈可能继续进行，可在记录中查看。

例如，用户有 600 秒分钟券、没有当日基础分钟：一题预留 45 秒后剩余 555 秒；未录音就退出后恢复 600 秒。退出前留下 12 秒片段并提交后，余额为 588 秒；继续这道尚未完整回答的题目时，重新预留 45 秒，余额变为 543 秒。这是时间额度示例，不代表一次 AI 请求的现金费用。

## 离线或服务暂时不可达

离线退出也会立即停止本页的麦克风和播放，但不能立即改变远端预留。页面明确显示「预留额度暂未释放」，不会把本机保存当作服务端已经释放。

浏览器允许持久存储时，退出请求和录音在本机按账号与录音授权隔离，最长保留 24 小时。恢复连接，或重新打开站点并确认同一账号后，自动同步待处理退出；继续作答前先补传已结束的片段。退出登录、切换账号、撤回录音授权或清除站点数据会使旧本机任务失效。

浏览器拒绝存储时只有内存暂存，页面会提示限制。此时请保持页面打开，等待退出与录音保存完成。强制关闭、系统终止和浏览器清理可能丢失尚未持久保存的最后片段，不能保证恢复。

## 模考与多个页面

尚未开始的模考可以退出后再开始；已经开始的模考退出记为「已中断」，保留回答和回放，不能恢复为继续计时。重新打开磁盘不会重置已开始模考的计时。

同一浏览器的其他页面收到状态变化后会校验服务端，停止旧练习的麦克风与播放，并保存片段。每次开始或暂停使用递增状态版本和独立事件标识：重复退出不重复退额度，延迟退出不能中断后来开始的练习。返回旧页面可重新载入当前记录。

不同设备、不同浏览器、离线或被系统挂起的页面无法保证实时收到本机通知。页面恢复焦点或心跳时会校验；旧状态的控制请求由服务端拒绝。仍需实际手机、后台切换及跨设备验证，不能据桌面自动化宣称全部通过。

## 升级与接口兼容

数据库迁移 `0007_session_pause.sql` 增加状态版本、当前开始事件和暂停补传名单，不删除已有业务记录。升级前完成私密备份，再执行正常迁移并重启网页与 worker；旧浏览器页面需刷新。

`POST /api/sessions/:id/events` 的 `start` 与 `pause` 必须携带最近读取的 `expectedVersion` 和本次唯一 `eventId`。暂停可以携带退出前的 `pendingUploads`；退出与自己的开始响应竞争时，可以携带该次 `startEventId`。状态冲突返回 `409 session_changed`，重新读取后由用户继续操作，不盲目重试旧版本。

补传名单最多 100 条，限定原会话有效题目与当前授权；新的暂停补传凭证只在退出后 24 小时内可申请。跨日继续按当日剩余题目与当日已用时长重新准入，不将昨日回答当作今日预留。分钟券到期、零预算、站点暂停或容量已满时，原记录保留，开始被拒绝。

## 当前验证范围与待完善项

本轮自动化覆盖分钟券释放与重扣、重复与过期事件、退出与开始竞争、跨日继续、已开始模考、预算/容量/授权拒绝、离线关闭重开及同浏览器两页暂停。数据库使用实际 PostgreSQL；界面检查使用 Edge、虚拟麦克风与加速计时，AI 为模拟服务。

自动化不能替代真人练习、手机 HTTPS、不同设备和教学验收。异常关闭时仍处于「录音中」的残留分片、跨设备并发接管，以及最终音频测得时长与申报时长不一致时的分钟券核对，继续列入优化清单。详细测试、截图与备份仅保存在被 Git 忽略的本机目录。
