# 已知限制

- 项目曾完成百炼 ASR/LLM 的合成语音转写和 JSON 连通检查；新安装不附带密钥，也不自动通过真实服务验收。真实口音识别质量与反馈教学质量仍需验证。历史模拟记录保留标识，不能据此判断英语水平。
- 140 道题及其参考回答是 AI 草稿。已检查数量、结构和引用关系，未完成全库人工教学审核。生产审核开关默认在示例配置中关闭，方便本机体验；正式试用应开启。
- 没有提供官方雅思分数。首版发音显示“未评估”；可选 Omni 诊断仍为实验功能，默认关闭。
- 原计划 Docker、手机及真实云服务完整验收尚未完成。当前完成 Windows 本机 PostgreSQL、Edge 虚拟麦克风的自动化流程，以及一次真实 ASR/LLM 连通检查。窄屏截图是响应式检查，不是手机真机结果。
- 当前没有公开部署，没有购买服务器、域名或云资源。Compose/Caddy 配置需在目标环境运行验证。Windows 本机完整备份、隔离恢复和恢复后的网页/worker 流程已验证，可运行 `npm run setup:backup` 准备客户端，用 `npm run check:recovery` 重复模拟服务演练；Docker 卷和 OSS 恢复仍待完成。较旧备份不包含后来密码变更和调用费用，切换前需核对，详见备份恢复说明。
- 应用内金额是配置单价计算的估算。调用前预留预算，成功后按返回用量结算；网络超时等计费结果不明的调用保留估算扣额，防止重试绕过预算。应用价格必须与实际模型和地域匹配，云账户本身仍需设置额度。服务诊断与 ASR 样本评测脚本也计入应用账本，沿用后台现有月预算。
- 单题/模考先预留录音时间额度，重复作答超出预留时另查当日余额；删除会话不会重置当日已使用的录音额度。月度金额按任务调用逐次检查，预算不足显示「等待预算恢复」，保留录音至原到期日及已完成转写，不自动重试；预算恢复后手动继续。
- 合成人声的真实上传/识别/反馈检查通过，但仍观察到建议重复与单题耗时约 50 秒的情况；尚不满足真人教学质量或 P95 时延验收，详见第三轮记录。
- 自然考官声音可使用 Kokoro 的 Emma 英式女声；模型需单独下载，它与转写、反馈分别配置。自动化测试使用短提示音加速，不能用于判断听感。
- 浏览器存储空间、无痕模式及系统强制终止会影响未上传录音恢复。已成功上传的音频保存在服务端；本地暂存最长 24 小时。退出或切换账号不应在共享电脑保留未上传录音。
- OSS 已发出的短期签名链接在到期或对象清理前仍可能有效；应用删除后立即停止签发。当前未用真实 OSS 验证。
- 现在只实现雅思口语。考公、考研、求职与其他英语面试列为后续模块，未伪装成已上线入口。
- 个人 API 设置首批只支持百炼北京地域的已列出 ASR 和 Qwen Plus / Flash 模型。连接测试仅验证反馈模型，不代表语音权限、真实口音质量、余额或优惠额度验证。
- 个人费用和站点费用分开记账；公共 TTS、每日训练额度及站点暂停开关仍由部署者控制。个人调用错误不会静默使用站点密钥。
