# 自然考官语音更新

2026-09-26：本机考官切换为 Emma 英式女声，使用 Kokoro-82M v1 的 q8 模型，正常语速的 95%。按句子生成、保留短暂停顿，长文本分段处理。生成结果统一转换为 MP3 并缓存。

声音由 `TTS_PROVIDER=kokoro` 独立配置；当前 `AI_PROVIDER=mock` 的转写、反馈仍是演示数据。自然语音无需云密钥，也不计云 API 费用；生成过程中只读取本机模型。首次下载模型需联网。

## 使用

1. 打开 <http://localhost:3000/device-check>，点击“试听考官声音”。
2. 已打开的练习页面先刷新，让浏览器获取当前声音。
3. 尚未缓存的题目首次需等待合成，worker 会在后台继续准备其余音频。

模型准备：`npm run setup:voice`。常用开场白和前四道题预热：`node --import tsx scripts/warm-voice.ts`。全部内容预热可追加 `--all`。无需重复下载已经缓存的模型。

## 首次准备与下载恢复（2026-10-10）

在项目目录运行：

```powershell
npm run setup:voice
```

没有 `.env` 时，命令按模板生成本机配置；已有配置不覆盖。控制台按文件显示已校验缓存、已下载 MB、百分比、重试与完成。模型校验结束后再加载本机推理依赖并生成试听。首次准备需要网络；考官合成期间不会自动尝试下载缺失模型。

固定的上游版本为 `1939ad2a8e416c0acfeecc08a694d14ef25f2231`，包含三个 JSON 文件与 q8 模型。大小和 SHA-256 写在源码清单中；模型哈希对应上游 LFS 对象，JSON 内容也核对过上游 Git 对象。参见 [固定版本的模型文件](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX/tree/1939ad2a8e416c0acfeecc08a694d14ef25f2231)。升级版本需要同时审核清单与模型许可，不能用一次下载结果替代后续完整性检查。

下载先写入同目录、带唯一标识的 `.part` 文件，完整字节数与哈希都通过后才替换正式文件。截断、零字节、相同大小但内容错误的缓存不会被当作可用模型；重跑命令会检查并修复。失败或正常取消只清理本次请求的临时文件，不清空整个缓存、不删除其他进程正在准备的文件。两个进程可能各自下载，最后只发布完整的相同版本；这里不承诺跨进程合并网络请求。

| 情况 | 处理 |
| --- | --- |
| 连接超过 30 秒，或连续 45 秒没有收到数据 | 停止本次请求，最多额外重试一次 |
| 所有文件与重试的下载等待超过 20 分钟 | 取消准备并返回非零退出状态；总上限不随分片刷新 |
| 下载期间按 Ctrl+C | 停止请求、清理本次临时文件，保留已校验的完整缓存 |
| 字节数或哈希不符 | 不发布文件、不自动重复同一错误；检查网络后重新运行命令 |
| 磁盘空间不足或目录不可写 | 停止准备，检查空间、权限或占用后重跑，不反复下载 |
| 面试进程发现模型缺失或损坏 | 合成失败并提示部署者先准备模型；不联网补下载、不改用付费语音 |

20 分钟上限约束下载阶段，不覆盖本机原生推理库的加载和试听合成。已经进入原生合成时，取消信号不能保证立即中止计算；程序在原生计算结束后再次检查取消状态，不发布新试听，也不将已取消的准备显示为成功。系统强制终止进程或断电可能留下带唯一标识的 `.part` 文件，它们不会作为模型使用，也不会在重试时覆盖正式缓存。若需回收其空间，先停止所有语音准备任务，只检查该固定版本目录内的 `.part` 文件；不要删除整个 `data/` 或其他账号的资料。

可直接打开生成的 `data/voice-preview/examiner.wav` 试听，再重启网页与 worker，进入“设备检查 → 试听考官声音”。听感仍需本人判断，文件生成或浏览器播放成功不等同于教学质量验收。

更换音色或语速后重启网页和 worker。旧音频保持可追溯，新的模型、音色和语速使用不同缓存；旧排队任务不覆盖新声音。已有会话在读取时更新声音资源，不修改题目版本、练习记录或截止时间。
