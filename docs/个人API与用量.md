# 个人 API 与用量

部署者恢复备份后，旧个人 Key 会在通过开放检查时清空，原服务模式与月预算保留。重新登录并修改临时密码后，请在本页重新填写 Key，或主动选择站点服务。已经核对的备份后费用以“恢复费用补记”列出，会计入预算，不增加调用次数；恢复不会清除已发生费用或自动提高预算。具体操作见 [备份恢复与回滚](备份恢复与回滚.md)。

入口：设置 → API Key、模型与用量（`/settings/ai`）。

目前支持阿里云百炼中国内地（北京）的按量付费密钥。语音识别可选 `qwen3-asr-flash-2026-02-10` / `qwen3-asr-flash`；文本反馈和追问可选 `qwen-plus` / `qwen-flash`，均为非思考模式和 JSON 输出。服务地址由服务器固定为官方北京接口，暂不接收自定义地址或其他平台密钥。

## 使用

1. 选择「使用自己的 API Key」，填写密钥、模型和个人月预算。
2. 确认录音与文本将发送给百炼处理、由你的账户计费，保存。
3. 如需验证，点击「测试已保存的反馈模型（少量计费）」。它只验证反馈模型并记账；语音识别权限仍需首次录音验证。保存本身不调用付费接口。
4. 后续转写、反馈与追问使用保存的配置。正在执行的请求使用启动时的配置；修改模型不会重算历史报告，也不会重定价历史消费。
5. 删除密钥后个人模式停止，后台不会悄悄改用站点 Key。要使用站点服务，显式切换模式并保存。已发生用量仍保留。

连接测试使用本次已保存配置，并与该账号的预算、模型设置变更串行执行；测试期间保存其他配置或删除 Key 会等待测试结束。不同账号的测试分别使用自己的密钥与账本，不额外提高并发上限或预算。每个账号每分钟最多测试一次；预算不足时不发出请求，也不改用站点服务。

个人模式不启用实验性音频诊断。考官提问和参考回答朗读继续使用站点 TTS 与缓存；默认 Kokoro 本地合成无云 API 费用。部署者如改用云 TTS，该项仍由站点预算控制。

## 消费的含义

- 费用按调用当时的单价快照估算，以人民币显示 6 位小数。输入与输出 Token 分开记账，ASR 优先采用供应商返回的秒数，缺失时采用服务器测量时长。
- 月份按北京时间自然月分界。账本只展示当前登录用户的调用，支持月份查询与分页。站点统一预生成的题目语音不分摊到用户明细。
- 本月预算是本应用的消费限制，不是供应商钱包余额。个人费用不计入站点月预算；每日录音分钟、并发和站点暂停开关仍有效。
- 调用开始前持久化预留预算，并发请求使用数据库锁避免重复透支。返回后按可用的用量结算；缺少用量的结果、网络失败或超时保留估算，显示「预留 / 估算」或「失败 · 待对账」。这不能证明供应商确实扣费。
- 优惠、免费额度、缓存折扣、其他 App 的调用及服务器费用不计入。没有获取或伪造云账户余额。

公开价格核对日期：2026-10-01，北京地域。ASR 原价 ¥0.00022 / 秒；128K 输入以内，Plus 输入 / 输出 ¥0.8 / ¥2 每百万 Token，Flash 为 ¥0.15 / ¥1.5。更长输入按官方阶梯估算。来源：[ASR](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash)、[Plus](https://help.aliyun.com/zh/model-studio/qwen-plus)、[Flash](https://help.aliyun.com/zh/model-studio/qwen-flash)。价格可能变化，目录维护在 `lib/ai/catalog.ts`。

## 密钥与部署

密钥采用 AES-256-GCM，随机 nonce，认证数据绑定用户 ID。数据库保存密文与尾号；用户接口不返回密文和完整 Key，浏览器不使用 localStorage / IndexedDB 存储 Key。数据仅通过同源、已登录、带 Origin 校验的接口提交。公网部署必须使用 HTTPS。

部署者可设置独立的 `USER_API_KEY_SECRET`（至少 32 位随机字符）；留空时用 HKDF 从 `BETTER_AUTH_SECRET` 派生。所有 web / worker 实例必须一致。备份时须单独安全保管这个密钥；更换有效加密密钥后原有个人 Key 将无法解密，需要用户重新填写，禁止回退成明文。站点运营者仍控制服务端，只在自己部署或信任的站点填写。

账号删除请求立即移除个人凭证，最终用户清理也有数据库级联约束。已经发往供应商的请求不能撤回，历史备份按部署者的保留策略处理。
