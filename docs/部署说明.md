# 部署说明

## 本地开发

按照 README 执行 `npm ci` 和 `npm run dev:all`。默认使用本机 PostgreSQL 17（5433）、本地私有存储和模拟服务。原始录音在 `data/storage/recordings/`；不要把 `data/` 映射成静态网页目录。

管理员首次改密后，在 `/admin/users` 创建试用账号。种子脚本只创建不存在的首个管理员，不会把已有密码重置为 `.env` 中的初始值。忘记密码的试用用户由管理员重置。

## Docker Compose

需要 Docker Engine/Desktop 和 Compose v2。当前交付环境未安装 Docker，因此这里是待目标环境验证的部署配置。

1. 从 `.env.example` 创建 `.env`；已有文件不覆盖。为 `BETTER_AUTH_SECRET`、`USER_API_KEY_SECRET`、`POSTGRES_PASSWORD`、`ADMIN_INITIAL_PASSWORD` 设置各自独立的随机值。前两项至少 32 字符，数据库密码推荐随机十六进制字符，避免 URL 特殊字符编码问题。
2. 本地入口保持 `BETTER_AUTH_URL=http://localhost:3000`。
3. 检查配置和启动：

```sh
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail 80 setup web worker backup
```

默认自然语音使用 Kokoro。新环境还需运行 `docker compose run --rm --no-deps web npm run setup:voice`，将模型下载到共享 `app-data` 卷，然后重启 web / worker。镜像不包含作者的模型缓存、个人 Key 或录音。

Compose 顺序为：PostgreSQL 就绪 → 迁移前备份 → 数据库迁移与种子 → web / worker。备份服务每天备份数据库和应用数据到主机 `./backups/`，保留最近 7 天的日期文件；持续维护的最新删除日志不随日期文件清理。

`postgres-data` 保存数据库，`app-data` 保存本地音频和删除日志。数据库端口不发布到主机，web 默认仅绑定 `127.0.0.1:3000`。不要使用 `docker compose down -v` 清理运行环境，否则会删除持久卷。

## HTTPS 与手机

在目标服务器配置：

```dotenv
APP_DOMAIN=你的域名
BETTER_AUTH_URL=https://你的域名
AI_PROVIDER=dashscope
TIME_SCALE=1
CONTENT_REQUIRE_REVIEW=true
SEED_PUBLISH_DRAFTS=false
```

把域名指向服务器，开放 80/443，然后执行：

```sh
docker compose --profile https up -d --build
```

Caddy 自动处理 HTTPS，代理到 web。手机浏览器访问 HTTPS 域名并授权麦克风。域名、云服务器、证书、云服务权限与网络可达性需在你的目标环境落实；本次未购买或发布任何云资源。中国内地部署相关条件依照原计划第 11 节落实。

使用本机网络隧道时，可将 `BETTER_AUTH_URL` 改为实际 HTTPS 地址，同时保持 `PORT=3000`，隧道转发至 `http://127.0.0.1:3000`。登录、注册、积分和个人 Key 接口的 Origin 必须与这个公网地址一致；重启网页与 worker 后统一使用公网地址访问。

应用通过邀请码注册或管理员创建账号。HTTPS 地址启用安全 Cookie。站点 API 密钥放在服务端环境变量中，个人密钥由 `/settings/ai` 提交并加密存入数据库；详情见 `个人API与用量.md`。服务检查和接口错误不回显完整密钥或云服务原始错误正文。

## OSS 私有存储

设置 `STORAGE_DRIVER=oss` 及 `OSS_REGION`、`OSS_BUCKET`、`OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`。必要时设置 `OSS_ENDPOINT`。桶保持私有；运行账号只授予对应前缀的读、写、列举、删除权限。

录音经应用鉴权后返回短期签名链接，URL 在过期前是持有者可用的临时凭证，不应分享。删除请求会立即禁止应用再签发链接，已签发链接可能持续有效至到期或对象被后台删除。若要求每次访问即时撤销，使用应用代理回放而非签名直链。

OSS 对象应单独制定备份策略；数据库备份不包含 OSS 二进制对象。本地存储的应用数据包包含音频。

## 日常运维

- `/admin` 查看队列、错误、worker 活动和反馈延迟；`/admin/tts` 查看考官音频状态。
- `/admin/usage` 调整额度、价格、预算和暂停新会话；默认价格是配置参考，按实际账户账单核对。
- 切换语音模型/音色后生成新的音频缓存，原练习仍保留原题版本。
- 暂停新会话后，历史记录与回放仍可用。后台已排队的任务仍会按预算检查处理。
- 保持 worker 运行；每天清理过期录音，每小时处理卡住的任务和无活动会话。
- 新版本使用独立 `APP_IMAGE_TAG`，保留上一版本镜像和迁移前备份。升级与回滚见备份文档。
