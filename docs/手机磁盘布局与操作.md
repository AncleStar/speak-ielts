# 手机磁盘布局与操作

训练页保留磁盘展示、题目说明和载入按钮。小屏竖屏按内容排列，横屏分别放置磁盘与题目；题目变长时页面可以滚动。磁盘模型的取景和绘制范围根据实际展示区域与状态文字调整，阵列不会延伸到页头和题目后面；不缩放模型本身，不添加插盘或圆环旋转效果。

在磁盘展示区域可以拖动或滚动选择磁盘，也可以使用上一张、下一张和题库索引。文字、页边与其他区域用于正常滚动页面，不应误切换题目。磁盘下方的「简洁显示」按钮用于停用三维显示，再次点击「启用 3D」可恢复。退出面试后回到当前选择的磁盘。

## 自动化检查

先完成生产构建，再运行专项：

```powershell
npm run build
npx playwright test tests/e2e/mobile-disc.spec.ts
```

测试在隔离数据库运行，检查 320×568、390×844 和 844×390 的载入按钮首屏可见、页面无横向溢出、展示区与题目排列、展示区外滚动不切题、展示区内滚轮选题、显示模式切换、载入时保留画布、面试栏与页头无重叠、退出回到当前磁盘和减少动画后的触摸按钮操作。滚轮检查等待浏览器的滚动结束事件后才开始另一段手势；按钮视口检查允许不足 0.05px 的亚像素舍入，不能容许原先半个按钮超出首屏的问题。测试使用合成账号与模拟服务，隐藏的两个测试提示条单独记录，详细截图保存在忽略发布的 `data/verification/`。

这属于 Windows Edge 的视口与触摸模拟。真实手机的触控、动态地址栏、Safari、输入法、权限与切后台行为，以及手机上的图形性能仍需在 HTTPS 站点上实际验收。录音与教学质量沿用独立验收门槛。
