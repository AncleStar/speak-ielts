# Personal Thought Lab · 个人观点实验室

入口是导航中的「自由练习」，地址 `/thoughts`。它把个人观点整理成可以修改、开口练习、长期积累的口语素材；原来的训练磁盘和限时面试继续从「训练磁盘」进入。

## 使用流程

1. 输入 3–2000 字的中文或英文观点，点击「生成三种表达」。
2. 查看 Simple（简单表达）、Natural（自然口语）、Nuanced（补充层次与取舍）。生成成功后自动保存到观点历史。
3. 直接编辑标题、原始观点和三种英文表达，然后保存。重新生成会保存成一份新观点，保留旧版本。
4. 点击「隐藏 Natural，开始练习」，先尝试表达，再显示原文对照。可以录音并回放，也可以填写尝试表达。
5. 勾选生成的词语，收藏到「个人词汇库」。收藏按用户和词语去重；已有词语的手动释义不会被重新收藏覆盖。
6. 将 Natural 加入「今日复习」，回想后自评，按 1、3、7、14 天安排下次复习。选择「还想再练」回到 1 天间隔。
7. 保存练习后，可从「成长日历」查看当天的观点练习和表达复习，点击足迹回到原观点。

三种版本代表表达风格，不对应 IELTS 分数。生成内容可作为改写的起点，使用前请检查是否准确表达你的意思。

## 模型与费用

- 沿用「设置 → API Key、模型与用量」中的反馈模型和服务模式。个人模式使用本人选择的 Qwen Plus / Qwen Flash；站点模式使用服务端配置。
- 每次生成是一笔 LLM 调用，输入与输出 Token 记入现有用量账本，调用前沿用个人或站点月预算预留。编辑、收藏、搜索和自评不调用模型。
- 同一个生成请求重复提交不会重复调用模型。每人每 10 分钟最多发起 6 次生成，并限制同时进行的生成。网络异常后重试可取回已经保存的结果。
- 个人密钥只保存在服务端加密配置中，不放入观点、提示词、浏览器存储或返回结果。此功能没有额外的密钥输入框。
- 生成会把输入观点发送给当前配置的服务商。请在自己部署或信任的站点使用个人 API。
- 站点使用模拟模式时，只显示明确标注的固定示例，不分析或翻译输入。真实输出的完整性会经过结构校验；不完整结果不存入观点历史，已发生的调用用量仍会记录。

## 录音与复习记录

录音保存在当前页面的内存中，只用于本次回放；不会进入面试上传队列，也不产生 ASR 用量。离开页面会释放录音与麦克风。录音最长 3 分钟，切到后台或设备断开时停止，不把中断录音作为成功练习。

「保存本次练习」保存录音时长及可选的尝试文本，不改变复习间隔。「已想起来 / 还想再练」记录自评并更新复习时间；这些记录不代表系统测评结果。

已保存的观点练习（包括文本练习）计入成长日历的练习天数和观点练习次数。浏览器记录的录音时长单独标记，不计入服务器解析的面试录音、语音检测统计或积分；表达复习次数是观点练习次数中的一部分。删除观点也会同步移除日历足迹。

未保存的观点编辑或练习在点击站内导航、切换观点、返回编辑、刷新或关闭页面时提示离开确认。浏览器返回/前进可能不显示确认，因此另外提供本机文本草稿恢复；离开仍会放弃当前录音。

## 本机草稿与共享设备

- 输入中英文观点、修改三种表达、填写回想文本时，自动写入当前浏览器的本机草稿，最长可恢复 24 小时；状态显示「草稿已在本机暂存」后才代表已成功持久保存。
- 刷新、返回、重新打开自由练习后，在「观点历史 → 本机草稿」选择恢复或丢弃。不同页面各有草稿，避免一个标签页覆盖另一个标签页的输入。正式保存、成功生成或保存回想练习后，清理对应草稿。
- 恢复已保存观点的草稿前，先读取当前服务端版本。若版本已更新，禁止直接覆盖；查看最新表达、手动合并并明确确认后才能保存。回想草稿也会提醒 Natural 的更新。
- 草稿只保存文本、版本及未确认操作的重试标识，不保存录音或 API Key。恢复普通文本练习的录音时长为 0；恢复尚未确认的提交时保留原提交和时长，用同一标识重试，避免重复记录。
- 草稿不会自动生成表达或上传到服务器，不产生模型费用，也不包含在服务端备份中。此前已开始的服务器任务不会因清除草稿而撤销。
- 退出登录会清除当前账号的本机草稿、未上传录音与音频分片；其他已打开的页面同步停止录音与上传。旧登录的异步写入不能重新写回已清除资料，延迟到达的清理也不能删除新账号的数据。
- 删除观点同时清理关联本机草稿，并通知其他标签页关闭旧编辑；本次登录保留删除标记，防止旧页面继续暂存该观点。
- 本机文本使用浏览器 IndexedDB，未加密。请在共享设备退出登录；浏览器禁用存储、容量不足或阻止数据库升级时，会明确提示仅在内存中暂存或需要手动清除本站数据，不承诺刷新后可恢复。系统强制关闭可能发生在最后一次写入之前。

每次练习保留当时的 Natural 文本。修改 Natural 后，已加入复习的卡片使用新表达，间隔重新从开始安排，过去的记录仍保留旧表达。页面显示最近 20 次练习，完整记录保存在数据库中。

观点历史和词汇库支持搜索与分页。删除观点会删除关联的练习、复习记录，已收藏词语保留且解除来源关联；删除账号时个人素材一并清理。个人数据沿用 `data/` 和数据库的发布排除规则。
