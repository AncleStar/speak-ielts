# 个人 API 与开源准备验收

日期：2026-10-01。

## 交付

- `/settings/ai`：个人密钥保存、替换、删除；ASR 与反馈模型选择；个人月预算；按月份和分页查询调用明细。
- 个人凭证绑定用户并经 AES-256-GCM 加密。API 仅返回尾号，写入检查登录和同源；不接受任意服务地址。用户停用或删除后停止后续模型调用。
- ASR、反馈和追问按调用者选择路由，个人费用与公共费用分账。删除 Key 不自动切换公共服务。考官 TTS 仍由站点提供。
- 数据库增加个人配置表、数据处理同意时间和用量的计费来源列。旧用量默认归类为站点承担，不修改历史价格或报告。
- MIT 许可证、第三方许可说明、开源发布说明、密钥与用量文档、源码检查与导出脚本。环境文件、私有数据及本地建模工程保留在本机并排除发布。
