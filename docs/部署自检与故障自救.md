# 部署自检与故障自救

在项目目录运行 `npm run doctor`，Windows 可双击「诊断应用.cmd」。它只读检查当前配置、依赖、表列、队列、心跳与模型，不创建账号、不迁移数据库、不重启服务、不下载或合成语音、不调用付费 API。模型校验期间仍会读取约 93 MB 文件，不能把这个命令当作持续高频探针。

需要 JSON 时使用：

```sh
npm --silent run doctor -- --json
```

存在失败项时退出码为 1；只有警告时退出码为 0，但报告状态是 `needs_attention`。`ok` 只表示本次列出的技术检查通过，不等于真人、手机、公网部署、教学或云余额验收。脚本不输出密钥、数据库连接地址、私人目录或厂商原始错误；仍应私密保管运行报告，不直接发布整个 `data/`。

| 检查 | 含义与处理 |
| --- | --- |
| Node.js | 需满足 22.12+；安装正确版本后在项目目录执行 `npm ci` |
| 认证及加密配置 | 检查长度，不检查随机性；已有个人 Key 时不要随意换加密密钥 |
| 计时与访问地址 | 测试倍率不能当作真实训练；HTTPS 配置通过也不代表证书、反代或手机已验证 |
| AI 配置 | 区分模拟模式及站点 Key 是否存在；个人 Key 在各自账号设置中核对，连通测试会另行计费 |
| FFmpeg | 检查版本输出与执行，不证明全部编码格式支持；训练流程另行验证 |
| 生产构建 | 检查可见的构建标识，不校验全部源码与编译内容；更新后重新构建并重启 |
| 数据库与表列 | 在只读事务中核对必需列；空库不会被自动迁移，不检查全部约束或用户资料 |
| 恢复保护 | 未核对时保持关闭；按恢复说明完成账号、费用与配置核对，不能手动删标记绕过 |
| 后台与队列 | 核对心跳及所需队列存在；不等于所有任务已处理，也不自动创建队列 |
| 考官模型 | 固定文件通过后仍需在设备检查页试听，见 [自然考官语音](自然考官语音.md) |

浏览器麦克风接口需要安全上下文。手机访问另一台电脑的局域网 HTTP 地址通常不满足要求，应在目标环境验证 HTTPS；本机 localhost 的可用性不能替代手机验收。依据 [MDN getUserMedia 安全要求](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia#privacy_and_security)。

## 后台未就绪

「管理 → 服务状态」和 `/api/health` 区分以下状态。健康接口不会输出配置摘要、密钥或目录，未就绪返回 503，并禁止缓存该次判断。

| 状态 | 下一步 |
| --- | --- |
| `missing` | 未收到心跳；启动当前版本的 worker |
| `stale` | 心跳已过期；检查后台错误日志和数据库连接，再重启 |
| `mismatch` | 近期心跳与网页配置或可见构建不匹配；统一配置并重启网页及全部 worker |
| `mixed` | 近期既有匹配也有不匹配的心跳；停止旧后台再统一重启。已停进程的旧条目最多等 60 秒过期，不代表一定还有两个进程存活 |
| `clock` | 存在超过 5 秒未来容差的心跳；检查网页、后台及数据库所在系统的时钟，不能靠修改预算修复 |
| `ready` | 存在匹配的新鲜心跳，没有上述冲突；不证明模型、云权限、声音质量或任务已经完成 |

新标识覆盖语音速度与声音、模型、实际服务配置、诊断/计时、数据和音频目录、云端点、密钥加密条件及可见构建标识。相关密钥只参与 HMAC 计算，保存的是不透明匹配值，不保存输入配置。运行进程只捕获一次构建标识，后台心跳沿用启动时的标识，不会因磁盘标记被替换就自动宣称已升级。相同物理目录的常见相对写法会归一化；不同挂载路径仍可能报告不匹配，需按实际部署统一。

本机自检只在实际归属于本项目的管理进程存在时采用它的运行编号；显式指定的运行编号保持。损坏或无法确认的状态文件不会被覆写，诊断给出警告。Windows 使用「查看应用状态」和「重启应用」；Docker 使用同一环境文件与镜像重启 web / worker。先暂停新会话并确认录音已保留，避免在录音中途替换运行时。

该机制诊断兼容性，不是任务执行隔离：不匹配的旧进程不会被自检自动停止，当前队列仍共享。处理配置故障时必须停止旧后台；任务来源绑定和滚动更新中的执行保护继续列为产品完善项。可见构建标识也不能替代全部源文件或镜像的可信校验。

## 常见恢复顺序

1. localhost 拒绝连接：先查看应用状态。未启动时用启动入口，持续异常时运行诊断；不要同时开多个手动服务。
2. 数据库能连但缺少表列：新安装按 README 初始化；升级先完成完整备份，再迁移，不清空业务目录。
3. 模型未准备：运行 `npm run setup:voice`，按进度完成后重启网页和 worker，再试听。
4. 恢复保护未解除：按 [备份恢复与回滚](备份恢复与回滚.md) 核对，不能用自检输出代替开放审批。
5. 站点 Key 或个人 Key 不可用：在相应设置中核对，明确选择计费的连通测试；自检不会静默切换密钥、模型或预算。

详细测试用合成账号、隔离数据库、虚拟麦克风和本机独立进程完成。手机系统后台行为、HTTPS、OSS、真人口音与教学质量仍须单独验收。
