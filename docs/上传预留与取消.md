# 上传预留、丢弃与额度

## 哪些时间会占用额度

| 状态 | 额度处理 |
| --- | --- |
| 正在进行的训练 | 预留剩余必答内容所需时间，暂停或退出后释放未用部分 |
| 取得上传凭证，尚未收到音频 | 暂时保护申报时长，显示为「待上传片段暂记」，不记录为已消费音频 |
| 服务端已经保存音频 | 计入消费；解码后以实测时长核对，多退少补 |
| 只丢弃未上传片段 | 撤销该片段暂记；进行中的整盘预留仍需退出练习才能释放 |
| 只丢弃已上传音频的本机副本 | 删除本机副本，服务器录音、反馈与已经消费的时间仍保留 |

分钟券和每日基础时间属于录音额度；AI 服务费用是另一套账本，丢弃音频不会撤销已经发出的转写或反馈费用。可用时间不足时不发起新的识别或反馈请求。

## 补传与过期

尚未上传的回答从**首次创建回答记录**起保留 24 小时暂记。单张上传凭证最多有效 15 分钟，接近补传期限时缩短；重领凭证不会延长最初的 24 小时。超过期限后不能再上传或为同一标识重领凭证，需要重新录音。

查询额度或进行钱包结算时，就会释放过期的未上传暂记，不依赖每日清理任务先运行。每日清理负责删除过期的空回答记录，并在账号钱包锁下再次检查、核对余额。释放券内时间不延长券的到期日；到期券恢复账面余额也不能再次使用。

已保存的音频不因 24 小时期限、撤回授权或删除练习而变成未消费。删除练习后保留真实录音的逐日额度账本，不能靠删除记录取回已用时间。中断片段可回放、补传，仍不能代替完整回答完成或解锁关卡。

## 离线丢弃

本机在同一笔浏览器存储事务中保存取消任务并删除录音分片。事务失败时保留录音并报错，避免只删文件却丢失取消任务。正在被其他页面录制或保存的片段不能丢弃。

离线时会显示「本机片段已丢弃，取消任务已保留」，同时说明服务器暂记尚未确认释放。恢复联网，或重新打开应用并确认当前账号后，自动同步取消任务。只有服务器确认后才显示暂记已撤销。

取消任务只包含练习标识、提交标识和当前登录/授权版本，不包含录音、题目文本或 API Key，保留最多 24 小时。退出、切换账号或撤回录音授权会清除相应本机任务；撤回授权也会在服务端释放尚未上传的暂记。浏览器无法持久存储时明确提示仅在当前页面内保留任务，不能保证关闭页面后同步；未上传暂记仍按服务端最初的期限释放。

服务端取消操作会保存提交标识的取消记录。同一取消重复到达不会重复退款；旧上传请求和延迟申请的新凭证不能让已取消的片段重新出现。上传与取消使用相同的账号录音锁：若音频已经先保存，取消只删除本机副本并报告已保存，不退还真实消费。

## 升级旧数据

仍保留回答明细的旧预留会按「服务端保存的音频 / 尚未上传暂记」重新核对。已经完全删除的历史练习可能只剩消费账本，无法可靠区分当时是否上传过音频；保留既有账本，不根据缺失数据猜测退款。需要人工核对独立备份或账单。

测试使用独立 PostgreSQL、模拟转写/反馈、Edge 虚拟麦克风和加速训练计时。它验证账户隔离、过期、重复取消、上传竞争、真实浏览器分片和存储事务；不代表真实手机、跨设备或云存储长时间上传已经验收。
