# 题库与资料来源

核查日期：2026-09-25。题库、追问、参考回答为原创 AI 草稿；以下资料用于核对格式、规则和接口，并不意味着官方授权、官方真题或已经由考官审核。

## 雅思格式

官方口语考试为三个部分，总时长 11–14 分钟；Part 2 包含 1 分钟准备和最长 2 分钟陈述。本应用固定采用 12 分 30 秒练习模板，训练模式的逐题倒计时属于产品训练设置。[IELTS 官方口语格式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-speaking)

官方练习材料用于核对题目类型与问答层次；没有复制成批真题或长篇参考回答。[British Council 口语练习](https://takeielts.britishcouncil.org/prepare/ielts-free-practice-mock-tests/academic/speaking)、[IDP 口语练习题](https://ielts.idp.com/prepare/article-free-speaking-practice-questions)

## 内容组织与审核

`content/ielts/meta.json` 统一标记 `sourceType=original`、`reviewStatus=ai_draft`。Part 1 共 60 题，Part 2 共 20 张卡片，Part 3 共 60 题。`npm run check:content` 检查关联、追问、关卡、模考和参考回答基本结构。

人工审核至少应检查：英文是否自然、难度是否符合章节、任务卡与收尾问题是否匹配、参考回答是否偏题、中文释义是否准确、反馈目标能否用可观察证据判断。完成审核后在管理后台把对应版本标记为 approved 并发布。修改内容会生成新版本，已开始的会话继续引用原版本。

## 真实服务接口

- ASR 使用 Qwen 音频识别的兼容接口，以 Base64 音频提交；服务端先转码与检查大小、时长。[阿里云 ASR API](https://help.aliyun.com/en/model-studio/qwen-asr-api-reference)
- TTS 使用百炼原生 HTTP 接口，合成音频后下载进私有缓存；默认音色 Jennifer，语言 English。[阿里云 TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)、[官方音色列表](https://help.aliyun.com/en/model-studio/qwen-tts-voice-list)
- 北京和其他地域的密钥/地址需要匹配；模型可用性应在实际账号核对。[阿里云非实时语音合成](https://help.aliyun.com/en/model-studio/non-realtime-tts-user-guide)

官方文档核对只能证明接口设计有依据，不能替代真实密钥下的调用与真机质量验收。
