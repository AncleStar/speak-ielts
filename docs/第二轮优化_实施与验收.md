## 如何试用

1. 打开 [本机登录页](http://localhost:3000/login)，原有账号继续使用。
2. 管理员在「后台 → 邀请码」创建邀请码；邀请码只在创建后显示一次，可复制给受邀者。注册入口在登录页。
3. 首页查看今日复习；练习报告可修正转写、重练或打开同题对比。
4. 「成长」查看日历与积分明细；「积分兑换」确认购买，成功后可选择再兑换一张。
5. 主页面顶部控制背景播放；「设置 → 外观」切换深色、减少透明效果和减少动态效果。

本机数据库、网页与 worker 已启动；这不是开机自启动。重启电脑后双击项目内 `启动应用.cmd`。手机不能通过自身的 localhost 访问电脑，手机麦克风测试需配置 HTTPS 访问环境。
