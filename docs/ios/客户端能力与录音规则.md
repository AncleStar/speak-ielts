# 客户端能力、导航与录音规则

能力边界定义在 [ports.ts](../../lib/ios/ports.ts)，仅是类型契约，尚无 Keychain、AVAudioSession 或 Capacitor 原生插件实现。

## 页面导航

一级入口：训练磁盘、观点实验室、复习、成长、我的。成长直接提供日历和签到，积分兑换在成长及我的各有明确入口；报告与历史回放从训练记录可直接进入。管理功能留在 Web 后台。

登录后沿用现有欢迎节奏。普通训练返回保存的当前磁盘，不跳回第一张；退出面试停止音频、录音及场景活动。盘面双圆环静止，不增加插盘或旋转动画。

录音前说明录音用途和第三方 AI 去向，完成 5 秒试音；系统拒绝麦克风时说明去系统设置修改，仍允许可用的文字与复习功能。额度不足、处理中和网络失败分别显示，不用同一种“加载中”覆盖。

## 账号与本机文件

文件、恢复索引和未保存草稿同时绑定 `userId + login epoch + consentVersion`。同一账号重新登录也产生新 epoch。退出、切换账号、删除或撤回授权会使旧异步操作失效，晚到结果不能写回新账号。

原生安全存储只保存会话所需凭据；原生私有目录保存录音，JS 使用受限的文件引用。不能任意读取路径，不能把会话或站点 Key 放进 Preferences、localStorage 或日志。

未上传录音最长恢复 24 小时；恢复操作不能延长原到期日。用户选择导出后，该外部副本不受应用内删除控制，需要明确告知。

## 状态与事件矩阵

| 状态/事件 | 行为 | 不允许的行为 |
| --- | --- | --- |
| 准备 → 录音 | 先停止考官音频，核对账号/授权，记录单调时钟起点并创建提交标识 | 复用旧账号文件、播放和录音互相回录 |
| 正常停止 | 封存当前完整片段，保存时长及状态，再进入待上传 | 根据页面动画估算实际音频时长 |
| 来电、切后台、锁屏 | 首版停止并封存已完成片段；普通训练返回后确认恢复，模考按原规则中断 | 隐式持续后台录音、重置模考服务端截止时间 |
| 音频路由变化 | 中断并确认耳机/麦克风可用后重新试音 | 自动拼接重复片段或假定设备未变化 |
| 强制终止 | 下次启动只扫描同一账号允许恢复的已落盘片段，标注中断 | 承诺最后未完成的写入一定可恢复 |
| 上传断网/超时 | 保留本机文件与稳定标识，查询服务器状态，用户确认后继续 | 每次重试生成新回答或直接退款未明费用 |
| 授权撤回 | 先停止本机录音、播放和上传；使旧版本失效，清理未上传录音 | 自动再次同意或继续处理晚到任务 |
| 退出/换账号 | 立即取消、失效 epoch，清除原账号资料及播放缓存 | 等网络请求完成才停止录音 |
| 账号删除 | 确认密码/意图后服务端失效，本机退出清理；保留清理失败说明 | 只隐藏 UI 而保留可用凭据 |

## 时间、格式及性能

录音时长使用单调时钟；服务端模考截止时间配合既有时钟偏移规则。回到前台重新核对状态，暂停的计时回调不能被当成新的开始时间。

候选格式 AAC/M4A 或 WAV，服务端按文件头核对并转成现有 ASR 所需格式；压缩率和蓝牙表现由真实 iPhone 样本决定。当前 25 MiB 文件上限与费用边界保持。

目标设备 iPhone 14 Pro，系统版本由用户报告为 26.6.2。小样要测磁盘切换、场景销毁后的内存、连续使用发热、录音/播放冲突和减少动态效果。不能以桌面模拟视口宣称实际帧率；必要时提供保持磁盘风格的轻量渲染。

VoiceOver、动态字体、安全区、键盘遮挡和横竖屏需独立验收。当前没有原生真机、后台或录音权限通过记录。
