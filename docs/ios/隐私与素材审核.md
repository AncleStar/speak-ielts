# 隐私、内容和素材准备

这份文件记录当前代码与原许可核查结果，以及提交前仍需确认的事项。不是已生效的公开隐私政策，不包含真实账户、联系地址或个人 Key。

## 数据流与保留规则

| 数据 | 当前用途与去向 | 当前规则/待补说明 |
| --- | --- | --- |
| 邮箱、昵称、密码认证信息 | 本机/后端账号系统；密码哈希由认证库处理 | 原生会话安全存储、忘记密码帮助及公开支持联系方式待接入 |
| 录音 | 本机暂存 → 私有后端 → 配置的百炼 ASR | 本机/未确认上传最长 24 小时；服务端每日清理超过 30 天的录音，清理调度须在目标环境验证 |
| 转写和反馈 | 后端及配置的 LLM | 用户可删除记录；录音到期不自动删除文字报告，需在政策中明确 |
| 观点和词汇 | 后端；生成观点时发送到配置的 LLM | 与账号绑定、编辑与删除；现有录音授权不能被视为所有文本共享都已独立完成审核 |
| 费用、额度与处理日志 | 后端账本与运维 | 展示为配置单价估算；未知计费不自动退款；删除和必要保留范围须最终核对 |
| 个人 API Key | 后端加密配置与调用 | 原生客户端不随包携带站点密钥；个人 Key 是否出现在 iOS 高级设置仍待定位 |
| 恢复备份 | 独立备份副本 | 恢复后重放删除日志；说明旧备份清理与保留期限，不宣称账号删除可即时撤回全部已导出数据 |

依据源码：`lib/services/deletion.ts`、`recording-consent.ts`、`lib/client/idb.ts`、`lib/auth.ts` 及个人 API 配置服务。撤回录音授权会停止新的上传/处理；已经发出的第三方请求无法收回。原生清理及第三方服务保留政策仍需核实。

## 准备好的政策内容结构

正式政策需要填写运营主体、支持邮箱、适用地区、生效日期和真实后端地址，并按部署结果确认：

1. 收集哪些账号、音频、文本、记录和用量信息。
2. 每项信息的目的、是否必需、处理方与实际服务地域。
3. 系统麦克风权限、录音/AI 处理同意及文字生成同意的区别。
4. 每类本机/服务端/备份数据期限及实际删除方式。
5. 查看、导出、撤回、删除账号与联系客服的入口。
6. 依赖和 SDK 的实际收集行为；首版无广告，不因为未安装分析 SDK 就默认填“无数据收集”。

App Store 隐私申报需要覆盖第三方伙伴；向第三方 AI 分享个人数据前需要明确说明和相应同意。原生账号删除入口应复用现有后端删除逻辑并验收。[隐私申报](https://developer.apple.com/app-store/app-privacy-details/)、[审核规则](https://developer.apple.com/app-store/review/guidelines/)、[账号删除](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion)

本包不生成“无需申报”的 `PrivacyInfo.xcprivacy` 假模板。选定原生插件后，根据实际 API 使用、SDK 清单和苹果理由代码生成，再验证其随最终构建交付。[Capacitor 隐私清单说明](https://capacitorjs.com/docs/ios/privacy-manifest)

## 题库与反馈工作表

[审核队列](generated/content-review-queue.csv) 包含全部 140 道主问题，优先标记首批 30 道；JSON 保存内容指纹、现有状态及待人工标识。模考 1 的 6 道追问与 1 道收尾题须同时核对，参照 [首批内容核对](../首批题库内容核对.md)。

复制 [记录模板](人工审核记录.example.csv) 到被 Git 忽略的私人目录，逐项填写题号、当前指纹、审核维度、意见、审核者和日期。至少核对自然度、贴题性、难度、中文、不同正确表达容忍度及来源。指纹变化后重新审核；确认后由后台审批发布，本工具不改变审核状态。

真人练习和反馈采用现有 [验收工作包](../验收工作包/README.md)，保留 20 次练习和 30 条反馈的人审记录，不能用合成音频替代真人证据。
