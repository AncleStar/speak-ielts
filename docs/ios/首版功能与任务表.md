# 首版功能与准备任务

首版免费、无广告，聚焦雅思口语。保留 SPEAK 磁盘体验、现有登录节奏、静态双圆环和 Emma 英式女声；iOS 管理操作沿用 Web 后台。

## 功能矩阵

| 能力 | 现有实现 | 移动端需要的准备 | 首版 |
| --- | --- | --- | --- |
| 邀请接入、邮箱登录 | `app/api/register`、Better Auth | 受控原生会话；邀请码可用，账号不对外自动创建 | 纳入 |
| 首次改密、入门设置、授权撤回、删除账号 | `app/actions/account.ts` | 分离网页重定向，复用业务规则并提供明确的移动响应 | 纳入 |
| 选盘、返回当前磁盘、退出面试 | `components/disc/`、会话服务 | 本地客户端导航、恢复当前磁盘、退出释放资源 | 纳入 |
| 录音、时限、上传、重试 | `lib/client/recorder.ts`、`uploader.ts` | 原生录音、文件落盘、生命周期、网络和授权版本适配 | 纳入 |
| 模考 | 会话计划、服务端截止时间 | 前台计时和中断保持原规则，不重置模考期限 | 纳入 |
| 报告、参考朗读、历史回放 | 回答/报告 API | 带会话鉴权的私有播放，Range、删除和缓存清理 | 纳入 |
| 观点实验室 | 观点 API 与组件 | 输入、保存、版本冲突、隐藏 Natural、练习录音适配 | 纳入 |
| 词汇与复习 | 词汇、复习 API | 页面导航、离线错误提示、重复操作一致性 | 纳入 |
| 签到、积分、兑换、日历 | 奖励、成长服务及部分 Actions | 把必要网页 Actions 迁成调用既有服务的接口，使用服务端日界与账本 | 纳入 |
| 个人 API 配置和费用 | 服务端加密配置、预算账本 | 保留 Web 能力；iOS 的可选高级设置待审核定位，正常试用不以填写 Key 为唯一条件 | 待定细节 |
| 推送、小组件、支付、社交登录 | 当前未作为首版依赖 | 不引入新增范围 | 后续 |
| 官方雅思评分、发音评分、其他考试 | 当前不提供官方评分；发音实验默认关闭 | 商店介绍与能力一致 | 不作首版承诺 |
