# 真人录音、手机与教学审核工作包

本目录是待执行的验收材料。合成人声测试、桌面虚拟麦克风和响应式截图均不能填写为真人或手机通过。不得把本表的准备状态改为题库 `approved`。

## 1. 真人识别与反馈

复制 `真实录音清单.example.json` 到本机 `data/acceptance/manifest.json`。在同目录放置自愿提供的录音，填入逐字回听核对的英文原话。示例中的文件名和原话都是占位符，不能直接运行。每种清晰、中文口音、噪声、停顿、静音至少先做一条；再增加不同说话者。

```powershell
npm run evaluate:asr -- --real --manifest data/acceptance/manifest.json
```

命令使用当前服务与现有预算，结果在 `data/asr-evaluation-时间.json`。WER 仅表示转写文字差异，不能作为发音评分。噪声、口音和长停顿必须来自相应的真人录音，不能用同一份合成音频代替。

随后让试用者在应用中完成实际录音与报告流程，并在 `真实练习验收.csv` 记录成功、失败恢复、转写含义、引用证据及建议是否可用。先收集 20 次完整练习和至少 30 条反馈；参照主验收文档检查成功率与 P95。未收齐样本时只报告已有数量，不推断达标。

## 2. 真实设备

在 `设备验收.csv` 填写实际型号、系统、浏览器版本、网络和日期。当前本机服务只监听电脑回环地址；手机需要另行准备可访问的 HTTPS 部署，不能输入手机自身的 localhost。此工作包没有部署公网服务。

逐项操作：登录；允许/拒绝麦克风；5 秒录音与回放；单题到报告；原速完整模考；切后台/锁屏；来电或音频中断；断网上传再恢复；刷新后的录音恢复。记录是否提示中断、是否漏音或重复上传、计时误差及恢复结果。只完成部分步骤时保留其他项未测试。

## 3. 首批题库人工审核

`首批30题人工审核.csv` 从已有核对清单提取问题 ID、内容指纹和训练目标，所有人工结论为空。审核者需要读题目、中文解释、追问、参考答案，并核对：自然英文、Part 匹配、难度与时长、训练目标可执行、参考答案相关且不唯一、无官方真题误导。

填入审核者、日期、问题、修改建议与通过/修改后复核结论。后台发布时重新核对版本指纹；原内容变更后需复核。此表不自动修改数据库状态。机器已核对的内容见上一级 `首批题库内容核对.md`，不能替代人工签名。
